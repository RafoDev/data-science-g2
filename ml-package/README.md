# Setup

Para crear el entorno virtual e instalar los requerimientos:

```bash
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
```

# Descarga del modelo

Para utilizar le modelo, es necesario exportar sus archivos y pegarlos en la carpeta `./model`.
