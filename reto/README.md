# Modelo de NLP

## Objetivos

- Aplicar conocimientos adquiridos sobre modelos de procesamiento de lenguaje natural (NLP).
- Desarrollar habilidades en la implementación de predicciones utilizando modelos pre-entrenados.
- Comprender el funcionamiento interno de los modelos NLP más allá del uso de pipelines.
- Demostrar capacidad para adaptar modelos existentes a casos de uso específicos.

## Descripción

Para este reto, se deberá implementar y/o afinar un modelo de NLP. Puedes basarte en los ejemplos desarrollados en clase, ya sean los modelos construidos desde cero o los ejemplos usando transformers.

> ⚠️ Importante ⚠️ : Si decides utilizar un modelo pre-entrenado, DEBES implementar tu propia lógica de predicción y NO limitarte a utilizar el pipeline del modelo.

## Entregables

- Código fuente comentado del modelo implementado.
- Documentación del proceso de afinamiento (si aplica).
- Demostración de predicciones con ejemplos.

## Criterios de evaluación

- Correcta implementación del modelo sin usar pipelines predefinidos.
- Originalidad en la aplicación o afinamiento del modelo.
